The browser engine is the unmodified JavaScript/WebAssembly pair from the
live demo linked by the official CoolProp browser documentation. The exact
upstream revision and download URL are recorded in vendor/SOURCE.txt.
The runtime version is checked during validation and is 7.2.0, matching the
original MATLAB application's Python CoolProp installation.

Browser model
-------------
Cycle logic, pressure/temperature controls, refrigerant catalog, application
presets and explanatory text were ported from the user-supplied MATLAB files:
vapor_compression_model.m, vc_input_state.m, vapor_compression_refrigerants.m,
and vapor_compression_scenarios.m. The interface and worker integration were
rebuilt for the course website. The original MATLAB files are preserved.

catalog.js contains the original metadata/presets and precomputed saturation
envelope points from CoolProp 7.2.0. These points are used only to draw the
background envelope. Cycle states, performance and process curves use live
CoolProp EOS evaluations, not interpolated property tables.

Application and refrigerant metadata
------------------------------------
The source app's GWP/ODP/safety assessment labels and application caveats are
retained. These are not newly verified equipment ratings or legal guidance.
Original application references are preserved in SCENARIOS.md and catalog.js.

ASHRAE safety/GWP metadata provenance from the original source:
ASHRAE 2026 Refrigeration Handbook chapter 1 table 2; EFCTC 2021 GWP assessment
comparison; NREL/TP-6A20-87372 appendix C; EPA 430-B-11-001 table 1; Danfoss
AB272556000550 ammonia guide; Arkema Forane 507A basic properties.
