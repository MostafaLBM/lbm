APPLICATION CONTEXT

Application scenario

Presets are illustrative refrigerant operating points, not equipment ratings. Temperatures are refrigerant temperatures, not room or ambient setpoints.

Model assumptions & refrigerant properties

Single-stage subcritical refrigeration, one adiabatic compressor, constant-pressure heat exchangers, an isenthalpic valve, no line pressure losses or motor losses. All superheat and subcooling are modeled inside the evaporator and condenser. The compressor path illustrates constant inlet-referenced isentropic efficiency. Blend properties use CoolProp’s predefined pseudo-pure equations of state: evaporation follows the dew-temperature input and condensation the bubble-temperature input, retaining temperature glide.

CO₂ cases model only a subcritical cascade low stage. Its displayed COP excludes the unmodeled high-stage plant.

Refrigerant properties are calculated locally using CoolProp 7.2.0 WebAssembly. Cycle logic, refrigerant information, and application presets are ported from the supplied MATLAB app. Attribution and sources.

No MATLAB installation needed. Calculations run in your browser.
